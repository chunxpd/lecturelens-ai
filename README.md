# LectureLens AI 2.0

대학 전공 교수자(인공지능·소프트웨어·데이터사이언스 등)가 YouTube 강의 영상 또는 로컬 MP4 강의 영상을 입력하면, 화면·음성·자막·수식·도식·코드를 종합 분석하여 **실제 영상 프레임이 삽입된 16:9 대학 강의용 PPTX**, **교수자 대본(.docx)**, **학생 배포용 PDF**를 자동 생성하는 웹 애플리케이션입니다.

## 주요 기능

1. **멀티모달 단계별 분석 파이프라인**
   - 0단계: 무료 Flash 계열 Gemini 모델 연결 및 응답 사전 점검 (`/api/test-connection`)
   - 1단계: 처음 30초(`00:00~00:30`) 우선 검증 분석
   - 2단계: 전체 영상 스토리라인, 장면 타임스탬프, 화면 자막/도식/수식/코드, 핵심 개념 및 참고문헌 추출
   - 3단계: 20종 교육용 레이아웃이 적용된 슬라이드 덱 및 교수자 구어체 강의 스크립트 생성
2. **실제 영상 프레임 자동 캡처 및 PPTX 삽입**
   - **YouTube 탭 자동 캡처 (`YouTube IFrame API + getDisplayMedia`)**: 1회의 현재 브라우저 탭 화면 공유 허용만으로 Gemini 분석 타임스탬프 구간을 자동 이동(핵심 3개 장면 검증 캡처 / 전체 장면 자동 캡처 지원)하고, 영상 플레이어 영역만 정밀 크롭(Region Capture 또는 좌표 크롭)하여 고해상도 PNG로 저장합니다. 광고·검은 화면·흐림·중복 화면은 자동 제외하며 작업 완료 시 화면 공유를 자동 종료합니다.
   - **MP4 자동 추출 폴백**: 허용된 로컬 MP4 업로드 시 **서버 FFmpeg** 또는 **브라우저 HTML5 Video/Canvas**로 주요 장면 프레임을 자동 추출합니다.
   - 미리보기 `<iframe>` 환경의 `display-capture` Permissions Policy 제한 시 상단 **독립 브라우저 탭에서 열기** 또는 로컬 PC(`http://127.0.0.1:3100`)에서 정상 동작합니다.
3. **고품질 수식·도식·멀티 포맷 내보내기**
   - KaTeX 수식을 고해상도 PNG 이미지로 변환해 PowerPoint에 삽입(원본 LaTeX는 발표자 노트에 보존)
   - 참고 `.pptx` 템플릿(색상/글꼴/레이아웃) 및 참고 `.pdf` 강의자료 업로드 반영
   - `.pptx`, `.docx`(교수자 대본), `.pdf`(학생 배포용), `.md`, `.json`, 일괄 `.zip` 및 앱 전체 소스코드 `.zip` 다운로드 지원
4. **IndexedDB 대용량 프로젝트 저장소**
   - 추출된 고해상도 프레임 이미지와 편집된 슬라이드를 브라우저 IndexedDB에 자동 저장

## 로컬(Windows / macOS / Linux) 실행 방법

### 1. 사전 요구 사항
- **Node.js 20 LTS 또는 22 LTS** 이상 (`node -v`로 확인)
- **Gemini API 키** (`GEMINI_API_KEY`)
- *(선택 권장)* **FFmpeg**: 로컬 MP4 업로드 시 서버 측 고화질 프레임 추출에 사용됩니다. (FFmpeg가 없어도 브라우저 HTML5 Video/Canvas 프레임 추출기가 기본 동작합니다.)
  - Windows: `winget install Gyan.FFmpeg` 또는 [ffmpeg.org](https://ffmpeg.org/download.html) 설치 후 `PATH` 등록
  - macOS: `brew install ffmpeg`
  - Ubuntu/Debian: `sudo apt-get install ffmpeg`

### 2. 설치 및 환경 변수 설정
```bash
npm install
```

프로젝트 루트에 `.env` 파일을 생성하고 `.env.example`을 참고하여 API 키를 입력합니다:
```env
GEMINI_API_KEY="여기에_본인의_GEMINI_API_KEY_입력"
APP_URL="http://127.0.0.1:3100"
```

### 3. 개발 서버 실행
```bash
npm run dev
```
실행 후 브라우저에서 `http://127.0.0.1:3100`으로 접속합니다.

### 4. 프로덕션 빌드 및 실행
```bash
npm run build
npm start
```

### 5. 코드 검증 (TypeScript 타입 검사)
```bash
npm run lint
```

## 설계 및 정책 준수 안내
- **YouTube 및 브라우저 권한 정책 준수**: YouTube 스트림 무단 다운로드나 광고 차단/우회 없이, 사용자의 명시적 화면 공유 동의(`getDisplayMedia`) 또는 적법한 로컬 MP4 업로드만을 통해 프레임을 확보합니다.
- **사실/보충 엄격 분리**: 모든 슬라이드와 장면 분석은 출처 `A`(영상 직접 확인), `B`(영상 연계 학부 보충), `C`(전공 교육 학술 추가)로 구분되며, 확인되지 않은 내용은 추측하지 않습니다.
- **무료 모델 우선**: `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite` → `gemini-4-hydrogen` 순으로 무료 지원 Flash 계열만 사용하며 유료 모델로 자동 전환하지 않습니다.

## Gemini + OpenAI 하이브리드 (선택)

- Gemini: 유튜브/MP4 영상·음성 분석, 장면 및 타임스탬프 추출. 처음 30초 테스트는 Gemini만 호출합니다.
- OpenAI: 전체 슬라이드와 발표자 대본의 분할 생성, 실제 캡처 이미지 판독 및 슬라이드 정합성 검증.
- 기존 브라우저 캡처, MP4 추출, PPTX 내보내기는 그대로 사용합니다.

로컬 .env에 다음 항목을 추가하고 서버를 재시작하세요. 실제 키는 저장소/채팅/소스 ZIP에 넣지 마세요.

```env
ENABLE_OPENAI_HYBRID=true
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
OPENAI_SLIDE_MODEL=gpt-4.1
OPENAI_VISION_MODEL=gpt-4.1-mini
```

Node.js 22 LTS 권장. 앱 강의 설정의 AI 분석 엔진에서 하이브리드를 명시적으로 선택하고 OpenAI API 연결 테스트(유료)를 실행하세요. Gemini 연결도 별도로 테스트해야 합니다. 모델명은 계정에서 접근 가능한 텍스트/이미지 및 Structured Outputs 지원 모델로 변경할 수 있습니다. OpenAI API 사용량은 서버 콘솔에 기록되며 사용료가 발생합니다. API 키가 없거나 오류가 발생하면 다른 유료 모델로 자동 전환하지 않습니다. 유료 모드에서는 서버가 127.0.0.1에만 바인딩되며 인증 없는 공개 배포는 지원하지 않습니다.

검증: `npm run lint`, `npx tsx --test tests/*.test.ts`, `npm run build`. OpenAI 테스트는 모의 HTTP 응답을 사용하여 비용이 발생하지 않습니다. 실제 영상 분석/실제 API 호출/브라우저 캡처/PPTX는 로컬에서 별도로 검증해야 합니다.

기본 로컬 포트는 3100입니다. 다른 앱과 충돌하면 `.env`의 `PORT` 및 `APP_URL`을 변경하고 서버를 재시작하세요.

## 자료 제작 방식 (두 가지 모드)

- 전공 심화형(기본): 기존 프롬프트·설정 유지. 영상에 전공 기술, 수식, 행렬, 실습 및 산업 사례를 보충합니다.
- 영상 충실형: Gemini로 영상에서 확인되는 화면·음성·기능·시연을 시간 순서대로 분석하고, 선택한 AI 엔진으로 원본 장면 중심 PPT와 발표자 대본을 작성합니다. 외부 이론·새 수식·코드·산업 사례·퀴즈를 자동 추가하지 않습니다. 실제 영상 화면 및 원본 영상 출처 중심으로 구성합니다. 자동 장수는 장면 수 + 표지/요약/출처(최대 32장)이고 지정 수량은 상한입니다. 짧은 영상의 내용이 적으면 목표 장수보다 적게 생성합니다. 전공 심화 옵션은 영상 충실형에서는 적용하지 않고 기존 값은 유지합니다. 모드 전환 후 전체 영상 분석을 다시 실행해야 합니다. 모델이 관찰한 내용 및 이미지 정합성은 실제 영상과 대조해 확인하세요.

## 클린 캡처 설정

실제 영상 화면 자동 캡처 패널에서 플레이어 UI 최소화 및 YouTube CC 자막 끄기 시도를 선택할 수 있습니다(기본 모두 켜짐). UI 최소화는 공식 `controls=0` 옵션을 사용하므로 미리보기 플레이어의 컨트롤도 줄어듭니다. 일반 조작이 필요한 경우 옵션을 잠시 해제하세요. CC 강제 해제는 공식 IFrame API에서 보장하지 않으므로 가능한 플레이어에서만 시도하며, 남아 있으면 사용자가 플레이어에서 CC를 직접 끕니다. 영상에 이미 삽입된 자막 및 픽셀은 수정하지 않습니다. 재생 상태에서 오버레이 소멸을 기다리고 새 화면 공유 프레임을 최대 3개 비교하여 시점·선명도를 기준으로 선택합니다. 이 방식은 UI가 전혀 없음을 보장하는 검출기가 아닙니다. 이전 캡처 버전 또는 설정이 다른 이미지는 다시 사용하지 않습니다. 새 캡처 전까지 기존 이미지가 표시될 수 있으므로 전체 장면 자동 캡처를 다시 실행하세요.
